# 手绘画板回归测试

运行 `npm run test:sketch`，验证图层排序、可编辑数据、工作流连线及失败保护。

可选的完整检查：

- `SKETCH_CANVAS_MODULE`：已安装的 `@napi-rs/canvas` 模块路径，用于真实像素合成测试。也可以直接在测试环境安装该模块。无需将其加入网站运行依赖。
- `SKETCH_TEST_API`：运行中的本地网站地址，例如 `http://localhost:5174`。启用后会测试 ZIP 打包、重新导入和资源读取，只接受本机地址。

两个可选项都可用时共运行 9 项测试。缺少环境时相关测试会明确跳过，不会访问外部生成 API。ZIP 测试使用合成图片与 `fixtures/sketch-pyramid.obj`，在系统临时目录生成检查用项目包，不读取用户画板或密钥。

手动验收：

1. 从左侧「手绘画板」进入，绘制线条，添加模型，确认角度。
2. 将绘画层上下移动，确认模型前后遮挡；用橡皮检查下层仍保留。
3. 检查锁定、隐藏、透明度、复制、撤销和重做。
4. 在 9:16 比例下生成，检查参考图、提示词、生成框连线及间距。
5. 点击手绘参考图重新打开，检查笔画、模型与构图。
6. 保存 ZIP，重新导入，在模型图层中再次打开 OBJ/FBX 场景继续编辑。

注意：这里的绘画层是二维构图，不是模型表面的贴图。改变模型角度后，笔画不会自动贴合新视角。

## 3D 基础模型与旧数据清理回归

运行 `node --test tests/model3d-primitives.test.mjs tests/model3d-storage.test.mjs`，验证球体尺寸与分段、参数边界、旧圆柱 / 方形兼容、替换几何体和过期撤销对象的资源释放，以及旧礼盒记录清理。清理测试直接写入旧格式 IndexedDB / localStorage，检查事务回滚、当前草稿优先级、导入项目不能重新引入旧模型，并保留其他模型和无关设置。

在隔离测试端口中打开「3D 模型预览」：模型库只显示球体、圆柱和方形；创建球体后，默认白膜、半径 100mm、水平分段 32、垂直分段 24。修改为 150 / 48 / 32，确认三角面变为 2,976；检查复制 / 撤销、保存关闭后恢复，以及导出到画布再继续编辑时参数保留。不要重置用户现有场景。

## 高清修复回归

运行 `node --test tests/upscale.test.mjs`。开发服务器的 `/tests/upscale-preview.html` 使用正式组件和本地绘制图片，禁止提交付费任务。

1. 打开高清修复，检查模式、倍数、尺寸；关闭后重开，确认没有黑屏。
2. 修改「画布保留内容」，点击「模拟弹窗渲染异常」，确认出现可关闭的错误提示。
3. 返回画布，确认输入内容保留，且可以重新打开正常的高清修复面板。

## fal 共享配置回归

运行 `node --test tests/fal-config.test.mjs`，验证旧会话密钥兼容、保存 / 清除通知、服务器配置查询合并、两类请求使用最新密钥、认证失败提示、旧请求不能覆盖新配置，以及会话存储不可用时的内存回退。

在隔离的本地测试页面中，从顶部「设置 → fal 专项服务」保存非真实占位文本，检查图层拆分和高清修复同步显示「已填写」；通过编辑器的「前往 API 设置」修改 / 清除后，选区、图层名称和修复参数应保留。检查完成后清除占位文本，不点击付费 Run。
